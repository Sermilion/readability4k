DLSS 5 now works on classic DOS games and Doom already has a functional build

With the DLSS Swapper mod, players can now apply DLSS 5 to the original Doom. The move arguably also opens the door to remastering other DOS games.
Rahim Amir Noorali, Published 10/05/2026 🇩🇪
Software Retro Gaming Game Releases Nvidia GPU
4
   
   

Modding DLSS 5 into all kinds of games and apps is the latest trend, and modders show no signs of stopping. Numerous tools let gamers port DLSS 5 into games, so they can implement and test the technology in their favorite titles. YouTuber Nikolai Zhivotenko has now opened the floodgates to what might be the first application of DLSS 5 to classic DOS games, aiming to create unofficial remastered versions.

DLSS 5 on the classic Doom

In his latest video, Nikolai walks viewers through applying DLSS 5 to the cult classic original Doom. Nikolai uses the Linux version (Doom v1.10), which is almost identical to the original MS-DOS version, save for a few minor changes. He uses the DLSS Swapper tool developed by rakanki911, available on GitHub.

A GitHub page under the name “niko-zvt” has been created, where Nikolai has provided the source and the files for this endeavor. According to MakeUseOf, DLSS 5 doesn't work with the Steam version of the original Doom. The mod only applies to Nikolai’s custom Windows port of the Linux version. Installation is relatively simple, with the full guide available in the GitHub description. 

Remastered Doom through DLSS 5: Is it worth it?

In their tests, MakeUseOf reports that while Nikolai has ambitiously termed the project a remaster of Doom, it falls short of that label. While the image quality is much sharper, the game feels almost the same overall, probably because of its age. DLSS 5 doesn't alter the game’s lighting or visuals as most would expect; instead, it just polishes some textures and parts of the HUD, even changing the color of Doomguy’s hair. 

Issues introduced by DLSS 5

However, implementing DLSS 5 seems to have regressed the gameplay experience in several ways. Because of its neural rendering technology, DLSS 5 introduces visual instability in high-motion situations, which are a major part of Doom. The game looks blurry, extremely so when surrounded by enemies. Even though textures and mesh quality may look sharp at first, it turns into a mess once the player starts moving. 

Another major issue, which anyone would expect, was the performance. While Doom is by no means a taxing game, implementing DLSS 5 significantly affected CPU usage, making the game’s performance feel inconsistent.

Final Verdict

DLSS 5 is a spectacular piece of technology that can visually enhance older games, as the evidence over the last few weeks shows. However, in this case, modders might be aiming too high. The age of DOS games might make them “unremasterable”. But this is an unofficial mod, and a native implementation could yield different results. For now, keeping an eye on the project would be sufficient.
